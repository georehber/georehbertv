GeoRehber TV kurulumu

Reklamsız ana ekran ve telefondan kumanda. Whale OS kullanan Android TV'ler için hazırlandı (Onvo SMART2KTVe üzerinde denendi).

APK dosyasını indir

1. Kurulum (USB bellekle)

  1. Yukarıdaki düğmeyle georehber-tv.apk dosyasını bilgisayara indirip USB belleğe kopyalayın.
  2. USB belleği TV'ye takın. TV'deki Dosyalar (File Browser) uygulamasıyla belleği açıp APK dosyasını seçin.
  3. "Bilinmeyen kaynaklardan yüklemeye izin verilsin mi?" sorulursa izin verip Yükle'ye basın.
  4. TV'nin uygulamalar listesinden GeoRehber TV'yi açın.

2. İzin (bir kez)

  1. TV'de Ayarlar → Cihaz Tercihi → Hakkında'ya girip Yapı (Build) satırına 7 kez basın. Geliştirici seçenekleri açılır.
  2. Geliştirici Seçenekleri'nde USB hata ayıklama'yı açın.
  3. GeoRehber TV'ye dönüp en alttaki Ayarlar satırından Ana ekran yap kartına basın. Çıkan soruda Her zaman izin ver'i işaretleyip onaylayın.

Bu izinle GeoRehber TV varsayılan ana ekran olur, telefondan yön tuşları çalışır ve güncellemeler sessizce kurulur. Bilgisayar gerekmez.

3. Whale ana ekranını kapatmak (isteğe bağlı)

Ayarlar satırındaki Whale ana ekranı kartına basın. Kapatınca RAM boşalır ve kumandadaki Kaynak tuşu GeoRehber'in kaynak penceresini açar. Aynı karttan istediğiniz zaman geri açabilirsiniz.

4. Telefon kumandası

  1. Telefon TV ile aynı Wi-Fi'deyken tarayıcıda TV ekranının sağ üstünde yazan adresi açın (örneğin http://192.168.1.xx:8080).
  2. İlk PIN 0000. Kumanda sayfasındaki Daha fazla → PIN'i değiştir ya da TV'deki Telefon Kumandası → PIN'i değiştir ile değiştirin.
  3. Tarayıcı menüsünden Ana ekrana ekle'yi seçerseniz kumanda telefonda simge olarak durur.

5. Güncellemeler

TV internete bağlıyken yeni sürüm çıkarsa ana ekranda Ayarlar satırının başında yeşil Güncelleme var kartı görünür. Karta basmanız yeterli.

Bilgisayardan kurulum (ileri düzey)

Android SDK platform-tools (adb) kurulu bir bilgisayarda, TV'de kablosuz hata ayıklama açıkken:

adb pair TV_IP:EŞLEŞTİRME_PORTU   (TV'deki 6 haneli kodu girin)
adb connect TV_IP:BAĞLANTI_PORTU
adb install georehber-tv.apk
adb shell cmd package set-home-activity com.georehber.tv/.MainActivity
adb shell appops set com.georehber.tv SYSTEM_ALERT_WINDOW allow
